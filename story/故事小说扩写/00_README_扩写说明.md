## 二、一句话概括这次扩写

大纲给的是**骨架**：四章、几个 Boss、几次转折、一个结尾。

扩写补的是**因果、人物、空间、代价**：

- 为什么第一章的敌人突然袭击生命基地？——不是无差别入侵，是万殖之巢扩张路线上的资源收割；生命基地只是第十八站。
- 为什么万殖之母要绑架布丽莎，而不是杀了她？——布丽莎是月井计划第七号“共鸣体质”，身体是一个能装下黑洞级能量的容器；万殖之母老了，需要一个新母体。
- 为什么布丽莎在黑洞里能活、能反击、能发出信号？——她的共鸣体质 + 教练机黑匣子的应急频段；每一次收集碎片释放的冲击波，都是她对外面的求救。
- 为什么黑洞 Boss 的防御那么高？——不是数值设定，是布丽莎在里面撑着；井壳在自我修复，因为她不肯屈服。
- 为什么结尾不是大团圆？——万殖之母逃了，十一口井还在，初母还没露面；女猎小队出发，是“未完待续”，不是“胜利”。

## 六、脚本使用建议

### 6.1 如果要做第三、四章

1. **先定视角与操作**：
   - Ch3：垂直俯视、房间式迷宫；Bryssa 步行；四个技能（相位护盾、镜像回声、引力锚、共振释放）；Boss 防守反击。
   - Ch4：纵版射击，从下往上；三架飞机；三个中 Boss 检查点；Proliferatrix + 井壳两段 Boss；90 秒逃亡。
2. **先做垂直切片**：
   - Ch3 先做“醒来 → 第一枚碎片 → 第一扇门”三段，验证俯视移动、共鸣视觉、护盾手感。
   - Ch4 先做“喉咙 → Fornax → 检查点”三段，验证纵版射击、编队、检查点。
3. **Boss 优先级**：
   - Carceratrix 的“防守反击”是 Ch3 的核心体验，先做护盾/镜像/引力锚的交互，再做弹幕。
   - 井壳 Boss 的“四环 → 接缝 → 三叉戟”是 Ch4 的核心体验，先做环的破坏反馈，再做三叉戟演出。
4. **不要先做数值**：井壳的“防御高”是叙事，不是血条；四环打完就该碎，不要做成“打十分钟”。

### 6.2 如果要做英文本地化/配音

- 第一、二章：以游戏内现有英文为准，不要按中文回译。
- 第三、四章：脚本 **附录 A** 给了关键台词英文建议；其余台词可按角色语气补译。
- 旁白：第三人称、短句、断行；不要用感叹号堆砌。
- 母体台词：短词、重复、错位语法；不要写成“反派演讲”。

### 6.3 如果要做续作

设定集第八节列了九个钩子，优先顺序建议：

1. **Proliferatrix 未死**：她从井壳碎裂的白光边缘溜走；续作可以让她成为“受伤的母体”，比全盛期更疯狂。
2. **初母**：银河系中心的“三只眼”；所有井的源头；人类与它的关系（“我们不是发现它，我们是从它身上学的”）。
3. **赛布尔是否还活着**：信号里的“第九号还在这里”；她可能是续作的向导，也可能是陷阱。
4. **布丽莎的代价**：共鸣核心受损；她可能再也飞不了，也可能变成比母体更危险的存在。
5. **Ally 的谎言**：它在第二章末尾隐瞒了信号残响；这个选择可以在续作里反噬。

### 小说与脚本的一处有意差异

- **小说终章**多写了一段“第一次出发后一个月”：女猎小队执行了四次任务、收到赛布尔“第九号还在这里”的新信号、并把线索指向银河系中心。这是为续作留的更长的尾巴。
- **脚本终章**做了压缩：5-02 直接给“十一口井 + 长期战争 + 明天出发”，5-05 用“新井 + 摇篮曲 + 初母的三只眼”收束。赛布尔的信号被留给续作，不在本脚本里展开。
- 两版的核心事件、人物关系、结局方向一致；差别只在“尾巴留多长”。若后续要做续作，建议以小说终章的版本为准；若要做本作收尾，脚本版本更紧凑。
