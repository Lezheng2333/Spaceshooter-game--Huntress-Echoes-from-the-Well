## 0. 文档说明

### 0.1 这是什么

这是一份**游戏剧情脚本**，不是纯文学剧本。它同时承担四件事：

1. 把 `故事大纲.txt` 的每一段事件拆成可拍摄、可实现的场景；
2. 给出角色台词、旁白、无线电与内心独白；
3. 标注每一段的镜头、演出、音频、HUD 与转场；
4. 标注哪些段落是**可玩关卡**，以及玩法视角、目标、机制与检查点。

小说负责“读起来完整”，脚本负责“做起来有据”。两者人物、时间线、台词互相咬合，但有各自的详略。

### 0.2 与现有游戏的关系

- **第一章、第二章的已实装台词尽量保留**：第一章开幕旁白、17 个分数节点的战斗无线电，第二章门禁、廊桥、球体、追逐、技能球、气室、研究室、Aggregatrix 的既有英文台词，均以游戏内文本为准；本脚本给出中文演出稿与场景重排。
- **第二章旧结局被新大纲取代**：旧版“Bryssa 把通讯设备装进货舱，回家”不再作为正史；新正史为“Bryssa 被井种带走，Martha 独自带回设备”。
- **Warden 更名为 Aggregatrix**：旧代码/旧文档中的 `Warden` 只作历史识别名；本脚本统一用“聚合母体 Aggregatrix”。首次出现时用一句 Ally 的识别台词完成更名，不破坏世界观。
- **第三章、第四章、终章为全新创作**：现有游戏只有占位旁白，本脚本按大纲补出完整关卡、解谜、Boss 与情感线。
- **章节编号建议**：Ch1 FIRST FLIGHT / Ch2 DEEP SPACE·MOONWELL / Ch3 THE GLASS PALACE（Bryssa）/ Ch4 THE NEST（Martha）/ Ch5 远航（续作入口）。旧占位 Ch3 ENEMY FORTRESS 的内容并入 Ch4；旧 Ch4 ASTEROID BELT、Ch5 FINAL ASSAULT 不再直接对应。

### 0.3 格式约定

| 标记 | 含义 |
|---|---|
| `【镜头】` | 摄影机/构图/视角 |
| `【演出】` | 动画、特效、场面调度、关键帧 |
| `【游戏】` | 可玩段落：视角、目标、机制、失败条件、检查点 |
| `【音频】` | BGM、音效、语音、静默 |
| `【HUD】` | 界面元素：血条、能量条、Boss 条、提示 |
| `【转场】` | 淡入淡出、白闪、黑场、折跃 |
| `【并行】` | 与另一章同时发生的交叉剪辑 |
| `（无线电）` | 经过通讯滤波的台词 |
| `（画外）` | 旁白/画外音 |
| `（内心）` | 角色内心独白，不做口型 |
| `【字幕】` | 屏幕文字/章节标题/旁白页 |

- 场景标题格式：`场号　内外景·地点·时间`
- 动作行用现在时；对白一行一句；重要台词附英文建议，统一放在 **附录 A**，正文不逐句中英对照，避免阅读割裂。
- 第一、二章已实装英文台词以游戏/`narration_scripts.xlsx` 为准；附录 A 只补第三、四章与终章的新台词建议。

### 0.5 语气基准

- **Martha**：年轻、克制、专业；短句，像无线电通话；不喊口号，不解释情绪。
- **Bryssa**：温暖、嘴硬、会哼歌；害怕时说废话、敲麦克风，不尖叫。
- **Ally**：冷静、字面、偶尔冷幽默；不用感叹号堆砌。
- **Vera**：命令式短句；叫呼号不叫名字；偶尔一句冷到骨子里的实话。
- **Nora**：语速快、爱开玩笑；越害怕话越多。
- **Oren**：预算表式语言；不谈感情，只谈代价。
- **母体**：短词、重复、错位语法；像心跳，不像演讲。
- **旁白**：第三人称、过去时、短句、断行；像旧科幻动画片头字幕。禁止网络流行语与“史诗感”台词。

## 3. 序章

### 0-01　外景·烬云星云·拾荒者九号·九年前

【镜头】全黑。只有一颗很远的、几乎看不见的星。镜头慢慢推进，星变成一个灰白色的点，点变成一枚翻滚的探测器。

【音频】没有 BGM。只有金属在真空里摩擦的、被夸张放大的低频。

【演出】探测器的主摄像头亮起。画面里出现一颗不该存在的星球：表面裂开一道口子，口子里伸出一座黑色尖塔，尖塔顶端悬着一颗黑球。黑球有三道暗坑，排成倒三角形。四道白环绕着黑球缓慢旋转。

【字幕】

> 月井计划·日志第九卷·第 41 条
>
> “井不是门。井是胃。”

【演出】探测器被黑球吸过去。黑球表面裂开一条白缝。缝里有一只手，很小，五指张开。

【音频】一段很轻的、像隔着水传来的摇篮曲。然后是一声心跳。

【转场】黑场。摇篮曲的最后一个音被掐断。

### 0-02　内景·生命基地·塔台·九年前·夜

【镜头】塔台内景。只有应急灯亮着。一个年轻的女人坐在通讯终端前，脖子上挂着一枚银色小铃。

【演出】终端屏幕上跳出一段波形。女人戴上耳机。摇篮曲从耳机里漏出来。她的手停在半空中。

【音频】摇篮曲 + 电流噪声。

女人（低声）

……谁在那里？

【演出】她的胸口起伏了一下。银色小铃自己响了一声。她伸手，把录音删掉。

【镜头】特写：删除确认框。她的手指悬在确认键上，停了三秒。

【音频】心跳。和序章 0-01 的心跳一模一样。

【转场】切黑。

### 0-03　片头

【字幕】

> 星历二十四年。
>
> 深空。

## 4. 第一章　最后的考核

### 1-01　外景·“生命”基地·停机坪·星历 24 年·晨

【镜头】低角度。灰色天幕下，绿色的穹顶像一只半埋在地里的眼睛。停机坪上停着三架白色主力战机，机翼上还带着防尘膜。最远的角落里，一架老教练机被三根钢缆吊在机库顶上。

【演出】Martha 站在教练机下面，仰头看。她穿着飞行服，胸前还没有徽记。Vera 从她身后走来，手里端着一杯冷咖啡。

【音频】基地的低频嗡鸣；远处有金属敲击声；风把灰尘吹过跑道。

Vera

它比你大。你出生的时候，它已经飞了十二年。

Martha

我知道。

Vera

它上一次进厂是四年前。左发慢性过热，起落架慢半拍，座舱加热器坏了。冬天飞它，你会冻得想哭。

Martha

我不哭。

【演出】Vera 看了她一眼，喝了一口咖啡，皱眉。

Vera

上去吧。考核还有最后一项。

【游戏】第一章·教学段（可选）：玩家第一次坐进教练机，学习 W/A/S/D 移动与空格射击。无敌人，只有靶机与跑道。完成后进入 1-02。

### 1-02　外景·灰星上空·考核空域·晨

【镜头】第三人称追尾。教练机在灰色的天空中爬升，左发冒出一缕白烟。

【音频】发动机的咳嗽声；警报的“嘀——嘀——”；Vera 在无线电里的呼吸声。

【演出】Martha 关闭左发。飞机向右偏。她踩舵、压杆、放襟翼，用一台发动机把飞机带回跑道。跑道只有一条灯带亮着。

Vera（无线电）

21395，你只有一次机会。跑道尽头是维修棚。

Martha（无线电）

我知道。

【演出】飞机在离地半米时左翼下沉。Martha 没有拉杆，反而推杆，用高度换速度。飞机重砸在跑道上，轮胎擦出黑烟，在离维修棚十七米处停住。

【音频】刹车的气动声。然后是很长的安静。

Vera（无线电）

……还行。

【镜头】特写：Martha 的手在操纵杆上发抖。她把发抖的手藏到杆下面。

【转场】切机库。

### 1-03　内景·“生命”基地·机库·昼

【镜头】机库大门打开，灰白色的光斜切进来。三架主力战机停在最里面，机身上刚喷好女猎徽记：白色箭头 + 三道尾线。

【演出】Vera 打开一个小盒子，取出一枚金属徽记，别在 Martha 胸前。

Vera

从今天起，你是女猎小队的人。呼号 Huntress-3。你的飞机——暂时是它。

【镜头】Vera 看了一眼角落里的教练机。

Martha

谢谢。

Vera

别谢我。谢你自己。你把那架老东西飞得像是它还有十年。

【演出】Bryssa 在机库门口等她，端着两杯合成咖啡。她把一杯塞给 Martha。

Bryssa

恭喜，Huntress-3。

Martha

别这么叫。

Bryssa

为什么？多威风。

【演出】两人并肩走出机库。镜头拉远：绿色穹顶、居住环、窗户、晾衣服的人、跳格子的孩子。

【音频】食堂方向传来跑调的生日歌。

【转场】切食堂。

### 1-04　内景·“生命”基地·食堂·昼

【镜头】热气、嘈杂、碗碟碰撞。Martha 和 Bryssa 坐在靠窗的位置。

【演出】警报突然响起。不是“嘀嘀”，是“呜呜”——低沉、断续，像铁皮房子里的野兽。

【音频】警报压过所有人声。碗掉在地上。

Bryssa（广播）

塔台呼叫所有单位。检测到大量不明飞行物，正在接近基地。所有战机紧急升空。重复：所有战机紧急升空！

【演出】Martha 放下筷子，站起来。她的身体比脑子先动。她已经在跑。

【转场】手持跟拍，冲过走廊。

### 1-05　外景·“生命”基地·停机坪·昼

【镜头】红色应急灯。机库门半开。Martha 冲进去，第一眼看见“长枪”的机翼插在墙上，第二眼看见“短刀”的空座舱，第三眼看见“弓”翻过来的尾部。

【音频】爆炸、金属撕裂、警报、远处有人喊“机库还有飞机！”

Bryssa（跑来）

玛莎！

Martha

你去塔台！我需要引导！

Bryssa

玛莎——

Martha

去塔台！

【演出】Martha 冲向角落里的教练机。钢缆松开，教练机从机库顶上滑下来。

### 1-06　内景·“生命”基地·教练机座舱·昼

【镜头】座舱内。座椅皮面裂开，弹簧硌着后背。仪表盘上只有一盏很小的蓝灯。

【演出】Martha 扣上头盔，按下启动键。左发咳嗽，熄火。再按。左发挣扎着转起来，温度指针顶到红区。

Martha

Ally，醒醒。

Ally（耳机）

早上好，玛莎。根据我的传感器，现在不是早上。根据我的传感器，我们正在被攻击。

Martha

你总是这么会挑时间。

Ally

这是我的设计缺陷。

【演出】教练机冲出机库。穹顶的裂口越来越大，菱形敌机像雨一样落下来。

Martha（无线电）

塔台，塔台，这里是 21395。我起飞了。

【音频】只有噪声。

Martha

塔台，21395，请求引导。

【音频】噪声。

Martha

布丽莎？

## 6. 第三章　镜宫

> **玩法总纲**：垂直俯视、房间式迷宫（参考初代塞尔达的“一屏一房”），叠加《尼尔：机械纪元》9S 骇入小游戏。节奏慢、压力低、以探索/解谜/轻战斗为主。Bryssa 的教练机不在身边时只能步行；她有一把维修用脉冲手枪（低伤害、可眩晕小怪、可触发环境机关），不能正面硬拼。每获得一枚能量碎片，恢复一部分能量，并**被动释放一次全屏冲击波**——这是第四章 Martha 收到的信号。

Wisp。

1. **Ch3 与 Ch4 并行**：Ch3 的最终救援必须与 Ch4 4-15 同一帧；如果先做完 Ch3 再做 Ch4，需要在 Ch4 用交叉剪辑补回，否则会损失“内外同时撕开”的爽感。
